Quick Access Tiles Checklist

  • ☐ Horizontal scrollable container, max 5 tiles visible
  • ☐ Fixed 70px height for menu bar dropdown
  • ☐ Content-type accent colors with gradient preview
  • ☐ Hover: blue border + medium shadow + -2px Y lift
  • ☐ Single-click paste (no confirmation needed)
  • ☐ Tooltip on hover: preview, app name, timestamp
  • ☐ Keyboard navigation: arrow keys, Enter to paste
  • ☐ Type badges for visual identification
  • ☐ Smooth scrolling, zero jank
  • ☐ Empty state: "No clipboard history"
  • ☐ Light/dark mode support (automatic via CSS vars)
  • ☐ Async thumbnail generation, no UI blocking
